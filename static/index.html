Conv2D

Learnable 3×3 filters detect edges, curves, and digit stroke patterns automatically.

MaxPooling

2×2 windows halve spatial dimensions while retaining dominant features and adding translation invariance.

ReLU Activation

f(x)=max(0,x) introduces non-linearity so the model can learn complex decision boundaries.

Softmax Output

Converts 10 raw logits to probabilities summing to 1. Argmax yields the predicted digit.

Build Process

Project timeline.

Phase 01
Dataset Preparation
Loaded MNIST (70,000 images), normalized pixels 0→1, applied mean/std standardization, reshaped to (1×28×28) tensors.
Phase 02
CNN Architecture
Two Conv2D blocks (32+64 filters), MaxPool for spatial reduction, Dense(128) + Dropout(0.3), Softmax head for 10 classes.
Phase 03
Training & Evaluation
10 epochs, Adam optimizer (lr=0.001), batch size 64, CrossEntropy loss. Achieved 99.34% test accuracy with F1 ≥ 0.99 across all classes.
Phase 04
Production Deployment
Exported to ONNX (0.02MB). FastAPI server with ONNX Runtime. Responsive frontend. Ready for Render / Railway deployment.
